Notification Direct Tester

Same payload contract as the Make.com version, but calls the send-notification-direct Supabase Edge Function instead — direct Slack/Resend/ClickSend API calls, no Make in the loop. Dev only, side-by-side comparison.

Requires each channel's secret to be set in Supabase (Dashboard → Edge Functions → Manage secrets): SLACK_BOT_TOKEN, RESEND_API_KEY + RESEND_FROM_EMAIL, CLICKSEND_USERNAME + CLICKSEND_API_KEY. Until those are set, that channel will respond with a clear config error rather than silently failing.
